# 如何游玩

## 基本规则

游戏在一个 4×4（默认）的网格上进行，游戏开始时面板上会随机出现两个数字方块（2 和 4）。

### 核心玩法

1. **移动方块** — 所有方块会沿你选择的方向滑动，直到碰到边界或其他方块
2. **合并方块** — 当两个相同数字的方块碰撞时，它们会合并为一个方块，数值为两者之和（例如两个 `2` 合并为 `4`）
3. **生成新方块** — 每次有效移动后，面板上会随机生成一个新的数字方块（通常为 2，偶尔为 4）
4. **游戏结束** — 当面板上没有空位且无法再进行任何合并时，游戏结束

### 计分规则

每次合并方块时，合并后的数值会累加到你的总分中。例如：
- 两个 `2` 合并为 `4` → 得 4 分
- 两个 `64` 合并为 `128` → 得 128 分

## 操作方式

### 键盘操作

| 操作 | 按键 |
|------|------|
| 上移 | `↑` 或 `W` |
| 下移 | `↓` 或 `S` |
| 左移 | `←` 或 `A` |
| 右移 | `→` 或 `D` |

### 鼠标操作

点击游戏界面右侧的方向按钮（`↑` `↓` `←` `→`）来移动方块。

## 游戏模式

### 经典模式

最经典的 2048 玩法。进入该模式前，玩家可以选择目标合成方块：

| 目标 | 难度 |
|------|------|
| 512 | 入门 |
| 1024 | 简单 |
| 2048 | 标准 |
| 4096 | 困难 |

当玩家成功合成出目标数值的方块时，即赢得游戏胜利。

### 挑战模式

限时挑战模式，玩家需要在固定时间内尽可能获得最高分数：

| 时间限制 | 难度 |
|----------|------|
| 30 秒 | 极限 |
| 60 秒 | 紧张 |
| 90 秒 | 适中 |
| 120 秒 | 宽松 |

- 剩余时间不足 10 秒时，时间显示会变为红色提醒
- 时间耗尽时游戏自动结束，最终得分取决于有限时间内达到的分数

### 无尽模式

没有目标分数和时间限制的自由模式：
- 游戏不会主动结束，直到棋盘被填满且无法合并
- 目标是尽可能达到更高的分数
- 随着游戏进行，棋盘上数字越来越大，合并机会越来越少，难度逐渐增加
- 适合练习策略和追求极限分数

### AI 模式

观看 AI 自动对局：
- AI 基于评估函数自动选择最优移动方向
- 可以观察 AI 的决策过程来学习策略

## 功能按钮

游戏界面提供以下功能按钮：

| 按钮 | 功能 |
|------|------|
| 加载存档 | 读取上次保存的游戏进度 |
| 保存游戏 | 保存当前游戏进度（游客无法保存） |
| 重新开始 | 重新开始当前模式的游戏 |
| 排行榜 | 查看当前模式的排名 |
| 退出 | 退出当前对局 |

## 菜单栏功能

| 功能 | 说明 |
|------|------|
| 重新开始 | 重置当前对局 |
| 保存 | 保存当前进度 |
| 撤销 | 撤销上一步操作（仅支持撤销一步） |
| 提示 | 提供下一步建议 |

## 设置

在主菜单点击「设置」可以进行以下配置：

- **游戏面板** — 选择棋盘大小（3×3 到 10×10）
- **颜色主题** — 选择 5 种颜色主题之一
  - Classic（经典）
  - Green and Blue（绿蓝）
  - Pink（粉色）
  - Blue（蓝色）
  - Yellow and Red（黄红）
- **自动保存** — 开启后每 30 秒自动保存一次游戏进度

## 用户系统

### 注册

- 账号不能包含非法字符（如 `?` `/` `\` `:` 等）
- 账号长度不超过 18 个字符
- 密码长度 8-20 位，需同时包含数字和字母
- 需要填写邮箱（用于密码找回）

### 登录

- 支持账号密码登录
- 支持游客登录（游客无法使用存档功能）

### 密码找回

通过注册时填写的邮箱验证身份后可重置密码。

## 评分等级

游戏结束后会根据得分给出评级：

| 分数范围 | 评级 |
|----------|------|
| ≥ 35000 | SSS |
| ≥ 21048 | SS |
| ≥ 12020 | S |
| ≥ 7250 | S- |
| ≥ 5500 | A+ |
| ≥ 3550 | A |
| ≥ 1850 | B+ |
| ≥ 1050 | B |
| ≥ 550 | C |
| < 550 | 无评级 |

## 游戏技巧

1. **角落策略** — 尽量将最大的方块固定在一个角落
2. **方向优先** — 选择两个主要移动方向，减少混乱
3. **保持空位** — 优先保持棋盘上有足够的空位
4. **避免中间大数** — 不要让大数出现在棋盘中间位置
5. **提前规划** — 在挑战模式中，快速思考比完美策略更重要
